# 3plug Repo Watchlist

## Purpose

This file tracks public repos that are relevant to Triotek's market direction but should not yet be treated as default dependencies.

These repos may be useful for:

* idea mining
* code review
* feature comparison
* selective adoption later

## Watchlist rules

Repos should stay on the watchlist if:

* maintenance is unclear
* compatibility is unclear
* code quality is unknown
* the repo solves only a niche one-off problem
* the domain is strategically important but the public ecosystem is weak

## Promotion rule

A watchlist repo can move to `approved-repos.md` only after:

* technical review
* license review
* compatibility review
* at least one concrete Triotek use case

## Strategic interpretation

If an area stays on the watchlist for too long and still matters commercially, Triotek should treat that as a signal to build and own the capability directly.
