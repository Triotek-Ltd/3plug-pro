# 3plug-pro Bootstrap

## Purpose

This file defines the intended local bootstrap pattern for developers.

## Local workspace pattern

Recommended local source areas:

* `rnd/3plug/sources/upstream-mirrors/`
* `rnd/3plug/sources/triotek-native/`
* `rnd/3plug/sources/catalog/`

## Principle

Developers should work against Triotek-controlled sources mapped to organization-owned repos under `Triotek-Ltd`.

Personal forks may exist for contribution convenience, but they should not be treated as the primary source of truth.
